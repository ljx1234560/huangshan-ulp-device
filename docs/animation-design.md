# 腕上表宠 前端动效详细设计方案

版本：v1.0（2026-11-10）｜负责人：组员三（前端）｜状态：待评审

本方案回应课程要求"前端动起来的详细设计方案"，是后续动效编码的规格书。所有参数以本表为准，真机校准后只调数值不改结构。

## 1. 设计原则与硬约束

| 约束 | 内容 | 对设计的影响 |
|---|---|---|
| C1 图片格式 | 设备仅启用 JPG/SJPG 解码，**JPG 无透明通道** | 宠物、配饰、背景全部烘焙在一张"整帧场景图"里；动画 = 对整图做变换，不做局部抠图动画 |
| C2 LVGL 版本 | v8（SiFli SDK 内置） | 使用样式变换 `transform_zoom/angle/pivot`，对任意对象可用（不依赖 lv_img），几何替身阶段即可开发 |
| C3 性能预算 | 主循环帧率目标 ≥30 FPS；动画期间不重新解码图片 | 动画只用 GPU/样式变换（zoom/angle/opa/位移），图片一次性解码驻留 |
| C4 单击/双击 | LVGL 原生不区分单击与双击 | 自研 250ms 时间窗判别器（见第 3 节） |
| C5 动画冲突 | 同一对象叠加动画会导致抖动/错位 | 每次播放动作动画前 `lv_anim_del(obj, NULL)` 清空，动作结束回调重启待机呼吸 |

## 2. 交互动作表（核心）

参数单位说明：zoom 256 = 100%；angle 单位 0.1°；时间单位 ms。

| 编号 | 触发 | 动画描述 | 参数 | 新素材需求 | 实现方式 | 优先级 |
|---|---|---|---|---|---|---|
| A1 | **单击宠物** | 开心跳两下（老师示例"点一下转圈"的落实：连跳比转圈更符合宠物性格，转圈保留为 A2 组合项） | zoom 256→276→256，每跳 300ms，共 2 跳；伴随轻震 | 无 | transform_zoom yoyo + 震动调用 | **P0** |
| A2 | **双击宠物** | 跳舞 2 秒：左右摇摆 ±15° + 上下弹跳，结束后回位 | angle ±150 三轮 + y 位移 ±12px 交错；总时长 2000ms | 无 | transform_angle + y 位移双动画序列 | **P0** |
| A3 | 长按宠物（600ms） | 睡觉模式：场景变暗、出现"Zzz"、呼吸放慢 | opa→55%、Zzz 标签淡入；再单击唤醒 | 无（Zzz 用文字标签） | 样式 opa 动画 + 状态标记 | P2 |
| A4 | 待机（常驻） | 呼吸：整图缓慢缩放 | zoom 256→264→256，周期 3000ms | 无 | 无限循环 yoyo 动画 | **P0** |
| A5 | 签到成功 | 弹跳欢呼：原地起跳两次 | y 上抛 -24px 两连跳，600ms | 无 | y 位移 yoyo ×2 | **P0** |
| A6 | 领取奖励 | 经验球从卡片飞到经验条 | 几何小圆点，x/y 路径 500ms，落地经验条 +8px 弹一下 | 无（几何替身） | 双段位移路径动画 | P2 |
| A7 | 升级 | 全屏庆祝：光芒缩放淡入 + 等级弹窗 + "太棒了"确认 | overlay zoom 216→256、opa 0→255，400ms | **已实现**（ui_common overlay） | 已上线 | **P0 已完成** |
| A8 | 换肤 | 旧场景淡出、新场景淡入 | opa 255→0→255，250ms 每段 | 无 | 样式 opa 过渡 | **P0** |
| A9 | 页面切换 | 新页横滑淡入 | x +24→0、opa 0→255，200ms | 无 | 进入动画（router 统一挂） | P1 |
| A10 | 聊天回复到达 | 宠物开心表情 + 回复气泡弹出 | 气泡 zoom 0→256（pivot 底部），250ms | 无 | transform_zoom + 呼吸暂停 1s | P1 |
| A11 | 步数达标 | 连跳欢呼（A5 加强版，三连跳 + 快速摇摆） | 900ms | 无 | 组合动画 | P2 |
| A12 | 皮肤页/任务页卡片按压 | 按下缩小回弹 | zoom 248→256，120ms | 无 | 样式 zoom + LV_STATE_PRESSED | P2 |

P0 = 本迭代必须（老师示例动作 + 基础生命感）；P1 = 下迭代；P2 = 视进度。

## 3. 单击/双击判别机制（C4）

```
CLICKED 事件
   │
   ├─ 距上次 CLICKED < 250ms ──→ 取消"单击待确认"定时器 → 触发 A2（跳舞）
   │
   └─ 否则 ──→ 启动 250ms 定时器（pending_single）
                  └─ 到时无第二次点击 → 触发 A1（开心跳）
```

- 判别器封装在 `ui_anim` 模块：`ui_anim_bind_tap(obj, single_cb, double_cb)`，所有页面可复用
- 长按（A3）用 `LV_EVENT_LONG_PRESSED`（LVGL 原生 400ms 阈值），与单击/双击互斥：长按触发后本轮回合作废
- 真机校准点：250ms 窗口要按用户实际连点速度调整（见第 6 节）

## 4. 素材规格（与生图管线衔接）

| 项 | 规格 |
|---|---|
| 场景图（主页舞台） | 220×176（5:4），JPG，质量 ≥85，**宠物 + 配饰 + 背景 + 光效一体烘焙** |
| 皮肤缩略图 | 120×96，JPG，由场景图等比缩放导出 |
| 形象页大图 | 220×176，与场景图同源 |
| 命名 | `skin_<id>.jpg`（default / sport_blue / flame_red / star_purple / rainbow）+ `pet_source_*.png` 源图（仅主机留档） |
| 源图 | 1024×1024 生成 → 居中裁 5:4 → 缩放目标尺寸；源图存 `assets/source/` 不进固件 |
| AI 定制皮肤 | 用户预设模板 + 提示词变量生成 → 同规格导出 → 文件系统就绪后走下载通道（内置皮肤不依赖文件系统） |

5 套默认皮肤的差异化（不只换色）：每套 = 形象特征 + 配饰 + 背景主题 + 动效节奏（A4 呼吸周期/A2 舞步幅度按皮肤配置微调，参数表见后续 skin 配置结构体）。

## 5. 实现架构

新增 `src/ui/ui_anim.c/h`，不依赖素材即可开发（几何替身阶段全部 P0 动作可跑）：

```
ui_anim.h
├─ ui_anim_bind_tap(obj, single_cb, double_cb)   单击/双击判别
├─ ui_anim_breathe(obj)                          A4 呼吸（页面进入时启动）
├─ ui_anim_stop(obj)                             清空动画（页面销毁时必须调用）
├─ ui_anim_happy(obj) / ui_anim_dance(obj)       A1 / A2
├─ ui_anim_cheer(obj)                            A5（签到欢呼）
├─ ui_anim_fade_in(obj, from_x)                  A8/A9 共用淡入
└─ ui_anim_press(obj)                            A12 按压反馈
```

接入点：`ui_home.c` 宠物舞台绑定 tap（A1/A2）+ 进入页启动呼吸（A4）；`ui_task.c` 签到成功回调接 A5；`ui_router.c` 切页统一挂 A9；`ui_skin.c` 换肤接 A8。所有动画回调不删除目标对象，页面销毁先 `ui_anim_stop` ——与既有"回调内不删自己"的安全纪律一致。

## 6. 真机适配校准清单（第 4 步执行依据，前置条件：固件编译通过）

| # | 校准项 | 方法 | 通过标准 |
|---|---|---|---|
| 1 | 单击响应延迟 | 串口 `ui_status` 打点 vs 屏幕反馈 | 手感 <100ms |
| 2 | 双击窗口 | 5 人各连点 10 次记录间隔分布 | 窗口覆盖 90% 用户自然连点，无误判 |
| 3 | 动画帧率 | transform 动画期间观测卡顿 | 目视流畅，无跳帧 |
| 4 | 动画时长观感 | 真机过一遍 A1–A9 | 模拟器参数若显拖沓整体 ×0.8 |
| 5 | 长按阈值 | 实测 LVGL 400ms 默认值手感 | 视情况调至 600ms |
| 6 | 内存 | 反复切页 50 次，堆水位 | 无泄漏增长 |
| 7 | 震动配合 | A1/A5 震动时机与动画对齐 | 无滞后感 |
